# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft that provides a wide range of services for building, deploying, and managing applications and business solutions. It supports different technologies such as computing, storage, databases, networking, artificial intelligence, analytics, and security. Azure allows organizations to use cloud resources through the internet without needing to maintain all of their own physical infrastructure.

## 2. Global Infrastructure

Microsoft Azure has a global infrastructure designed to provide reliable, secure, scalable, and high-performance cloud services. Azure operates through a large network of regions and data centers around the world. Its global infrastructure allows organizations to deploy applications and store data closer to their users, which can improve performance and reduce latency. Azure also focuses on sustainability, security, and flexibility to support modern cloud and artificial intelligence workloads.

## 3. Cloud Management Console

The Azure Portal is a web-based management console that allows users to create, configure, monitor, and manage Azure resources from one centralized location. Through the portal, users can manage services such as virtual machines, databases, storage, networks, and applications. It provides an intuitive interface that helps users efficiently manage their cloud resources from the cloud to the edge.

## 4. Four Core Services

### Azure Virtual Machines (VMs)

* Provides virtualized computing resources that can be used to run applications, operating systems, and other workloads in the cloud.

### Azure Blob Storage

* Provides scalable object storage for large amounts of unstructured data such as documents, images, videos, backups, and application data.

### Azure SQL Database

* A fully managed relational database service based on the Microsoft SQL Server database engine, designed to provide high performance, scalability, and reliability.

### Azure Virtual Network Manager

* Allows organizations to create and manage virtual networks across different Azure regions and subscriptions from a centralized location.

## 5. Three Advantages

### Azure Free Account

* New users can explore Azure services through a free account that provides access to selected services and resources for a limited period or within specified usage limits.

### Azure for Students

* Eligible students can receive Azure benefits, including free monthly allowances for selected services and Azure credit that can be used to explore and learn about cloud technologies.

### Azure for Nonprofits

* Eligible nonprofit organizations can receive Azure grants and discounts that can help reduce the cost of cloud services and support their digital transformation projects.

## 6. Typical Enterprise Use Cases

Microsoft Azure is commonly used by enterprises for:

* Hosting websites, mobile applications, and business applications
* Storing and backing up business data
* Managing and running cloud databases
* Migrating existing IT infrastructure to the cloud
* Developing Artificial Intelligence and Machine Learning applications
* Supporting business continuity and disaster recovery
* Building scalable enterprise applications
* Managing cloud-based networking and security
