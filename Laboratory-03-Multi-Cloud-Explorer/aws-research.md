# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon that provides a wide range of services over the internet. These services include computing, storage, databases, networking, security, analytics, application development, and other cloud-based solutions. AWS allows individuals, businesses, and organizations to use technology resources on demand without having to purchase and maintain their own physical servers. AWS follows a pay-as-you-go pricing model, where customers generally pay for the resources and services they use.

## 2. Global Infrastructure

AWS has a large global infrastructure designed to provide reliable, secure, and scalable cloud services. Its infrastructure is organized into Regions and Availability Zones (AZs). Each AWS Region contains multiple Availability Zones that are designed to operate independently while remaining connected through high-speed networks. This setup helps applications remain available even when problems occur in one location. AWS also uses a global network backbone to support fast data transfer, lower latency, and better performance for applications and services used around the world.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Through the console, users can create and configure cloud resources, monitor services, manage security settings, and view account and billing information. It also provides search and navigation features that make it easier for users to find different AWS services. AWS CloudShell is also available through the console, allowing users to run command-line commands directly from their browser.

## 4. Four Core Services

### Amazon EC2

* Provides virtual servers for running applications and workloads in the cloud.

### Amazon S3

* Provides scalable object storage for files, documents, images, backups, and other data.

### Amazon RDS

* Provides managed relational databases that make it easier to set up, operate, and scale databases.

### Amazon CloudFront

* A content delivery network (CDN) that delivers websites, applications, videos, and other content to users with reduced latency.

## 5. Three Advantages

### Trade Fixed Expense for Variable Expense

* Instead of spending a large amount of money purchasing servers and building data centers, businesses can use AWS resources when needed and pay based on their usage.

### Benefit from Economies of Scale

* AWS serves many customers using its large-scale cloud infrastructure. This allows customers to access computing resources at a lower variable cost compared with maintaining similar infrastructure independently.

### Stop Guessing Capacity

* AWS allows organizations to increase or decrease their resources according to demand. This reduces the need to predict infrastructure requirements far in advance and helps prevent both overprovisioning and insufficient capacity.

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for:

* Hosting websites and web applications
* Storing and backing up business files and data
* Running and managing databases
* Developing, testing, and deploying software applications
* Building scalable and highly available business systems
* Analyzing large amounts of business data
* Implementing cloud-based security and monitoring solutions
