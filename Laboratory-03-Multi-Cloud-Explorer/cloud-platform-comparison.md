## Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** offers the broadest range of cloud services among the three major cloud providers. It provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, application development, and many other areas. Its large service portfolio allows AWS to support different types of organizations, from small startups to large enterprises.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the best choice for organizations that already use Microsoft technologies. Azure works closely with products and services such as Windows Server, Microsoft 365, and Microsoft Entra ID. This integration can make it easier for organizations to manage users, applications, security, and cloud resources within a Microsoft-based environment.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud** is a strong choice for Artificial Intelligence and Kubernetes workloads. It provides AI and machine learning services that can be used to develop and deploy intelligent applications. Google Cloud also offers **Google Kubernetes Engine (GKE)**, a managed Kubernetes service that helps organizations deploy, manage, and scale containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose **AWS** because it provides a wide variety of cloud services that can be useful for different types of projects. AWS also offers services covering many areas of cloud computing, including computing, storage, databases, networking, security, and application development. Learning AWS would help me gain experience with different cloud technologies and prepare me for future IT projects and career opportunities.
