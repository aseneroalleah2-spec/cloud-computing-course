# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform developed by Google. It provides a wide range of services that help organizations design, build, deploy, and manage applications and other cloud-based solutions. Google Cloud offers services for computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, and application development. These services allow businesses and developers to use cloud resources without having to maintain all of their own physical infrastructure.

## 2. Global Infrastructure

Google Cloud has a global infrastructure consisting of regions and zones located around the world. To build applications with high availability and fault tolerance, Google recommends deploying applications across multiple zones and, when appropriate, multiple regions. This approach helps protect applications from unexpected failures affecting individual components, zones, or even entire regions. Google's global infrastructure also helps organizations deliver applications and services efficiently to users in different locations.

## 3. Cloud Management Console

The Google Cloud Console is a web-based graphical user interface that allows users to manage their Google Cloud projects and resources. Through the console, users can create and configure cloud services, monitor resources, manage security and access permissions, and view information about their cloud environment. It provides a centralized way to manage Google Cloud resources without requiring users to work entirely through command-line tools.

## 4. Four Core Services

### Compute Engine

* A computing and hosting service that allows users to create and run virtual machines on Google's infrastructure.

### Cloud Storage

* A managed object storage service used to store unstructured data such as documents, images, videos, backups, and application files.

### Cloud SQL

* A fully managed relational database service that supports database engines such as MySQL, PostgreSQL, and SQL Server.

### Google Kubernetes Engine (GKE)

* A managed Kubernetes service that allows organizations to deploy, manage, and scale containerized applications using the Kubernetes platform.

## 5. Three Advantages

### Faster Time to Market

* Google Cloud allows organizations to quickly create or remove computing resources. Developers can deploy applications faster and respond quickly to changing business requirements.

### Scalability and Flexibility

* Cloud computing allows businesses to adjust their resources according to their workload. Organizations can increase resources when demand is high and reduce them when demand decreases.

### Cost Savings

* Google Cloud uses usage-based pricing for many of its services, allowing organizations to pay for the resources they consume. This can reduce the need for large investments in physical servers and other infrastructure.

## 6. Typical Enterprise Use Cases

Google Cloud can be used by enterprises for:

* Hosting websites and business applications
* Data analytics and large-scale data processing
* Artificial Intelligence and Machine Learning
* Database management
* Running global applications
* Developing and deploying cloud-native applications
* Managing containerized applications using Kubernetes
* Storing and processing business data
